# Ideas

This document contains the ideas that have not yet been finalized but have a chance of being implemented.

# List of ideas

## Clipboard

- Preview for images in clipboard history
- Smart automatic paste (with configuration file for rules)
- Delete entries
- Pin entries

## Launcher (fuzzel features)

- File search
- Project launcher (with configuration file for projects list)
- Unified launcher (menu for selection a needed launcher)
- Fuzzel like main interaction menu

## Customization

- Live wallpaper support
- CLI themed environment (unlikely)
- General themes for system

## Custom TUI Login Manager

- Animated ASCII art on boot
- Session selection
- Time
- Themes
- Wayland-support
- Random quotes upon logging in
